# 🌸 Pastel Pink Calculator

A simple pastel-themed calculator built using Python and CustomTkinter.

## Features
- Basic arithmetic operations (+, -, *, /, %)
- Clear (C) button
- Backspace (⌫)
- Keyboard support
- Pastel pink user interface

## Technologies Used
- Python
- CustomTkinter

## How to run
- Clone the repository
- Make sure Pyton is installed on your system
- Run the Python file
